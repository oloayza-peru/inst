# Dashboard de Control de Avance de Inspecciones - Instrumentación
**Contrato N° 3700002135 | Refinería La Pampilla (Repsol Perú)**  
**Desarrollado para:** ADEMINSAC PERÚ

Este proyecto contiene una aplicación web interactiva desarrollada en **Streamlit** y **Plotly** para el control ejecutivo de avance de inspecciones de instrumentación, gestión de OPS y monitoreo de eventos de seguridad.

---

## 🚀 Archivos del Repositorio

- `app_control_inspecciones.py`: Código principal de la aplicación Streamlit.
- `requirements.txt`: Dependencias requeridas para la ejecución y despliegue en la nube.
- `README.md`: Instrucciones de uso.

---

## 🛠️ Instrucciones de Ejecución Local

1. **Clonar o descargar este repositorio.**
2. **Instalar las dependencias:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Ejecutar la aplicación Streamlit:**
   ```bash
   streamlit run app_control_inspecciones.py
   ```
